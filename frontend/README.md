# LifeQuest frontend

Prompt 1 scaffold only: placeholder pages and components, routing, and shared types.

```sh
cd frontend
npm install
npm run dev
```

Open the local URL printed by Vite. To compile for production, run `npm run build`.
Use `npm run preview` to preview the build locally.

Routes: `/`, `/home`, `/planner`, `/quests`, `/shop`, `/wardrobe`, `/garden`, `/cafe`.

Production hosting must rewrite page routes to `index.html` for BrowserRouter.
